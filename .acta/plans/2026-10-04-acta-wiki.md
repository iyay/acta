# Project Wiki Implementation Plan

> **For agentic workers:** run this plan with acta:build, task by task. Steps use checkbox (`- [ ]`) syntax, and acta reads those boxes as task progress.

**Goal:** acta reads a project wiki in `.acta/wiki/`, hints a page when the agent touches the files it covers, checks that pages stay true, and has build write the pages and land gate them, at 0 tokens for a repo with no wiki.

**Spec:** `.acta/specs/2026-10-04-acta-wiki-design.md`

**Tests:** fast `scripts/test ./internal/<package> -run <Name>` for the package a task names, omp `(cd plugin && bun test omp/index.test.ts)`, full `scripts/test --full`; land also runs `go vet ./...`, `gofmt -l .`, `(cd plugin && bun test)` and `scripts/eval` with the branch binary on PATH.

## Global Constraints

- Follow acta:lean: understand the task and the code first; then skip it, reuse code here, stdlib, a native feature, an installed dependency, one line, the minimum; never cut validation, security or accessibility.
- Never use the name "okf" in code, text or file names. Page fields: `type`, `title`, `description`, `paths`, `timestamp`. Types: `Decision`, `Gotcha`, `Runbook`, `Reference`, `Glossary`.
- Exact limits: `description` is one line of 120 characters at most; a body is 250 words at most; the session start wiki text is 45 words at most and appears only when `.acta/wiki/` holds a page.
- Every `acta wiki` command is read-only: it never writes a file and never commits. A hint never makes a hook exit non-zero. Exit 2 stays only for the blocks that exist today.
- A new test package calls `testguard.Watch()` in its `main_test.go` (copy `internal/write/main_test.go`). Tests that run git use `t.TempDir()` repos. Tests that touch config set HOME to a temp dir and `t.Chdir` into a temp repo.
- Byte caps in `internal/plugincheck/budget_test.go` move in the same commit as their file. A new file gets a cap at its real size. A cap goes up only for growth this plan names. `plugin/skills/shape/` stays within its 177-line cap.
- Run steps use `scripts/test ./internal/<package> -run <Name>`, never bare `go test` and never `./...`. An eval costs quota: run only the case the task names, with the branch binary first on PATH: `go build -o "$TMPDIR/acta-bin/acta" ./cmd/acta && PATH="$TMPDIR/acta-bin:$PATH" scripts/eval --case <name>`.
- Never run `rm -rf` or `rm -f`. Scratch files live under `t.TempDir()` or `$TMPDIR`.
- Comments are plain English a 10-year-old can read. They say why, not what. No marker comments.
