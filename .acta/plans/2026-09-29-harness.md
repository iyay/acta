# Harness Implementation Plan

> **For agentic workers:** run this plan with acta:build, task by task. Steps use checkbox (`- [ ]`) syntax, and acta reads those boxes as task progress.

**Goal:** Hooks remember which scratch item a session brainstormed and block a second one, plugincheck guards the new wiring, and a `claude plugin eval` suite tests agent behaviour before skill changes land.

**Architecture:** Two new `acta hook` subcommands (`pre-tool`, `post-tool`) share a small state file `.acta/state/sessions.json`; `acta hook prompt` reads it for a reminder line. Two shell wrappers wire them into `hooks.json`. Eval cases live in `plugin/evals/`, run by `scripts/eval`; the land skill calls it only in a repo that has `scripts/eval` and only when the diff touches `plugin/skills/` or `plugin/hooks/`.

**Tech Stack:** Go (`internal/hook`, `internal/cli`, `internal/plugincheck`), POSIX shell, `claude plugin eval`.

**Spec:** `.acta/specs/2026-09-29-harness-design.md`

## Global Constraints

- Implement ponytail-lazy: YAGNI, then existing code, then stdlib, then native, then an installed dependency, then one line, then the minimum; never cut validation, security or accessibility.
- omp is out of scope (SCRATCH-15). No change to `plugin/omp/`.
- Every hook path exits 0 except the block path of `acta hook pre-tool`, which exits 2. Bad JSON, a missing file or a missing `session_id` never blocks and never prints an error.
- State file: `.acta/state/sessions.json` under the acta root (`config.Load(...).Root`), kept out of git with `hook.EnsureGitignore(cfg.Root, "state/")`.
- `scripts/eval` runs `claude plugin eval` with `--model sonnet --ablation none --no-publish --allow-tools Bash`. No `--max-cost-usd` (the user is on a subscription). Each case sets a low `max_turns` and `timeout_seconds`.
- LLM graders (`haiku`) only for case 3 (second brainstorm offers three choices) and case 4 (obvious one-file fix skips Architectural). All other graders check files or commands.
- Comments and skill text in plain English a 10-year-old can read; say why, not what.
- Gates before every commit: `gofmt -l .` prints nothing, `go vet ./...` is ok, `go test ./...` is green.

func TestBrainstormStem(t *testing.T) {
	cases := []struct {
		cmd, stem string
		ok        bool
	}{
		{"acta set scratch/2026-09-28-harness-spec status brainstorming", "2026-09-28-harness-spec", true},
		{"cd x && acta set scratch/a-b status brainstorming", "a-b", true},
		{"acta set scratch/a-b status raw", "", false},
		{"acta set specs/a-b status brainstorming", "", false},
		{`echo "acta set scratch/a-b status brainstorming"`, "", false},
		{"", "", false},
	}
	for _, c := range cases {
		stem, ok := BrainstormStem(c.cmd)
		if stem != c.stem || ok != c.ok {
			t.Errorf("BrainstormStem(%q) = %q,%v want %q,%v", c.cmd, stem, ok, c.stem, c.ok)
		}
	}
}

func ev(session, cmd string) ToolEvent {
	var e ToolEvent
	e.SessionID, e.ToolInput.Command = session, cmd
	return e
}

func TestPreToolBlocksSecondItemOnly(t *testing.T) {
	root := t.TempDir()
	first := ev("s1", "acta set scratch/one status brainstorming")
	if block, _ := PreTool(root, first); block {
		t.Fatal("first brainstorm must pass")
	}
	if err := RecordBrainstorm(root, first); err != nil {
		t.Fatal(err)
	}
	if block, _ := PreTool(root, first); block {
		t.Fatal("same item again must pass")
	}
	block, msg := PreTool(root, ev("s1", "acta set scratch/two status brainstorming"))
	if !block || !strings.Contains(msg, "one") || !strings.Contains(msg, "three choices") {
		t.Fatalf("second item: block=%v msg=%q", block, msg)
	}
	if block, _ := PreTool(root, ev("s2", "acta set scratch/two status brainstorming")); block {
		t.Fatal("another session must pass")
	}
}

func TestParseEvent(t *testing.T) {
	for _, in := range []string{"", "{bad", `{"tool_input":{"command":"x"}}`} {
		if _, ok := ParseEvent(strings.NewReader(in)); ok {
			t.Errorf("ParseEvent(%q) ok, want false", in)
		}

	e, ok := ParseEvent(strings.NewReader(`{"session_id":"s1","tool_input":{"command":"ls"}}`))
	if !ok || e.SessionID != "s1" || e.ToolInput.Command != "ls" {
		t.Fatalf("got %+v %v", e, ok)
	}
}

func TestReminderNamesItem(t *testing.T) {
