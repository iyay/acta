# Review Debt Implementation Plan

> **For agentic workers:** run this plan with acta:build, task by task. Steps use checkbox (`- [ ]`) syntax, and acta reads those boxes as task progress.

**Goal:** Review NOTEs land in `.acta/debt/` files as ticked-or-open checklist items with DEBT ids, shown on the board, CLI and TUI.

**Architecture:** A new board kind `debt` (one per file) with children of kind `debt-item` (one per checklist line), built the same way plans carry task children. `acta debt new` writes the file like `acta bug new`. `acta tick` learns to rewrite one checklist line and a `--wontfix` box `[-]`. Skills route NOTEs to `acta debt new` instead of memory.

**Tech Stack:** Go 1.27, Bubble Tea TUI, markdown skill files guarded by `internal/plugincheck`.

**Spec:** `.acta/specs/2026-09-26-review-debt-design.md`

## Global Constraints

- The spec was written before the rename: read `pmb` as `acta`, `pm:` as `acta:`, `.pm/` as `.acta/`, Task 2 writes the debt commit as `pm: new debt <stem>` to match the code at that time; Task 7 then moves every acta commit prefix to `acta:` (user ruling 2026-09-27).
- Folder config key `dirs.debt`, default `debt`.
- Box states: `[ ]` open, `[x]`/`[X]` done, `[-]` wontfix. File status `done` when every line is closed, else `open`. Progress counts `[x]` and `[-]` as closed.
- Ids: file `DEBT-n` / `DEBT-<hash>`; line `DEBT-n.m` / `DEBT-<hash>.m`; path id `debt/<stem>#item-N`; lower case resolves.
- Implement ponytail-lazy: YAGNI, then existing code, then stdlib, then native, then an installed dependency, then one line, then the minimum; never cut validation, security or accessibility.
- Comments: plain English a 10-year-old reads, say why. No marker tags.
- Gates before every commit: `gofmt -l .` prints nothing, `go vet ./...` clean, `go test ./...` passes.
- TDD: write the failing test first, watch it fail, then the minimum code.
