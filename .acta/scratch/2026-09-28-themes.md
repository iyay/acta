# Theme support

User, 2026-09-27: theme support for the TUI.

Not approved work yet. Brainstorm when picked up.

Brainstorm 2026-09-29. Reference: terminalcolors.com (catalog of 16-ANSI + bg/fg schemes, no API). Current TUI uses fixed ANSI-256 indexes in internal/tui/view.go:59-75, so it ignores the terminal theme.
User ruling: option c - default follows the terminal (ANSI 0-15 only, no config); optional named preset in acta config with built-in hex colors. Path: Architectural (new config surface).

User ruling: preset choice lives in user-level config, not the repo. Existing user file is ~/.acta/voice.yaml (internal/voice/voice.go); candidate home for the theme key.

User ruling: presets = small built-in set in Go (about 4, hex from terminalcolors.com) plus user files at ~/.acta/themes/<name>.yaml.

User ruling: approach A - theme file = 16 ANSI slots + bg/fg (same shape as terminalcolors.com). Each acta role maps to a fixed slot. Default theme "terminal" has no hex, so slots render as ANSI indexes and follow the terminal.

Approved section 1 (shape):
- New package internal/theme: Theme{Name, BG, FG, ANSI [16]string}, ~4 built-in presets, Load(name) looks in ~/.acta/themes/<name>.yaml first, then built-ins; unknown name = error naming it.
- Voice gets key theme: (empty = terminal), set via acta voice set theme <name>.
- The 5 global styles in internal/tui/view.go:57-76 move into a styles struct built from the Theme and held on Model.
- Fixed role slots: accent=12, work=4+faint, dim=8, selected fg15 on bg0 (dark) / fg0 on bg7 (light).
- terminal mode renders slots as ANSI indexes; light/dark pick uses the existing dark flag in tui.New.

User ruling: default theme (empty theme key) = tokyo-night, not terminal. "terminal" stays a selectable built-in. Fallback on a bad theme = tokyo-night.
Tokyo Night default hex (terminalcolors ghostty file): bg #1a1b26 fg #c0caf5 selection-bg #283457 selection-fg #c0caf5; palette 0 #15161e 1 #f7768e 2 #9ece6a 3 #e0af68 4 #7aa2f7 5 #bb9af7 6 #7dcfff 7 #a9b1d6 8 #414868 9-14 same as 1-6, 15 #c0caf5.
Finding: slot 0 (#15161e) on bg #1a1b26 is nearly invisible as a selected band, so the theme shape gains optional selection_bg/selection_fg (terminal files already carry them); absent = slots 0/15.
